M.M. English Medium Mission Website — updated starter

OPEN:
1. Extract this ZIP using Windows "Extract All".
2. In VS Code choose File > Open Folder.
3. Select the extracted project folder that contains index.html and the assets folder.
4. Open index.html, then open it in Microsoft Edge to preview.

CHANGE THE LARGE POSTER LATER:
Replace assets/poster-banner.png with your own edited poster image. Keep the exact filename poster-banner.png. You do not need to edit index.html for that replacement.

IMPORTANT:
- Keep the assets folder beside index.html.
- The enquiry buttons open the Microsoft Forms URL supplied by the user.
- The phone number is set to 9064333262.
- The Google Maps link uses the location URL supplied by the user. The embedded map is a searchable area map; the external Google Maps link opens the shared pin/location.
- Verify all facilities are actually available before publishing.
